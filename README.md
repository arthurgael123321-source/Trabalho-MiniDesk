# Trabalho-MiniDesk
Trabalho em grupo de uma atividade proposta na aula de "Métodos ágeis de desenvolvimento de sistemas"

## FitTracker

Dashboard responsivo para gerenciamento de treinos, com visão semanal, métricas de desempenho, exercícios recentes, objetivos e criação de novos treinos.

### Executar localmente

```bash
npm install
npm run dev
```

Para gerar a versão de produção:

```bash
npm run build
```
